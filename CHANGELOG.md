## [26.10.3] - 2026-10-21

- Install, update, disable and remove trusted provider extensions from npm or git in Settings → Extensions.
- Updated the built-in Pi SDK to 1.3.0.

## [26.10.0] - 2026-10-20

- First public release of Learnvas: branching AI conversations on an infinite canvas.
- Branch from selected passages and merge conversations, choosing which history to include.
- Compare models and supported thinking-effort settings without replacing earlier answers.
- Use optional web research with source links.
- Personalize tutoring with global and per-thread notes.
- Read Markdown answers with code, tables and zoomable Mermaid diagrams.
- Move, resize and collapse cards; choose light/dark themes or zen mode.
- Built with the Pi SDK for the AI backend and React Flow for the canvas.
- AppImage with signed update support and built-in recovery; tested on Pop!_OS only.
